# 🛒 BharatKart

BharatKart is a modern e-commerce web application built with HTML, CSS, JavaScript and Firebase.

## 🚀 Features

- User registration and login
- Firebase Authentication
- Product listing from Firestore
- Shopping cart
- Quantity management
- Checkout flow
- Order management
- Order status updates
- Customer profile
- Responsive UI
- Firebase Firestore database

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Firebase Firestore
- Font Awesome
- Google Fonts
